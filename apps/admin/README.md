# গেমের প্রকাশনা ঘর

একবার নিজের পাসওয়ার্ড দিয়ে প্রশাসক তৈরি করুন। **গেমের কনটেন্ট** থেকে পরিচয়, চরিত্র, মানচিত্রের লেখা, অভিযান, চায়ের দোকান, জিনিস, পয়েন্ট, যান ও পত্রিকা সম্পাদনা করুন।

১. **খসড়া সংরক্ষণ** চাপুন।
২. **খসড়া গেমে দেখুন** দিয়ে খেলে দেখুন। প্রিভিউর অগ্রগতি নিয়মিত সেভে যায় না।
৩. **গেম প্রকাশ করুন** চাপুন। সাধারণ গেম আবার খুললে নতুন সংস্করণ আসবে।
৪. **প্রকাশ ও ইতিহাস** থেকে আগের প্রকাশ ফিরিয়ে আনা যায়। খসড়া রাখা হয়।

লোগো ও চরিত্রের ছবির জন্য অনুমোদিত স্থির ছবি দিন। ছবিটি পোর্ট্রেট হিসেবে ব্যবহার হয়। নিজস্ব ত্রিমাত্রিক চরিত্রের ফাইলে গেমের মূল রিগ, মাপ ও প্রয়োজনীয় অ্যানিমেশন থাকতে হবে। **ঘটনার শব্দ ও কণ্ঠ** থেকে বাংলা সংলাপসহ অনুমোদিত কণ্ঠ প্রকাশ করুন।
