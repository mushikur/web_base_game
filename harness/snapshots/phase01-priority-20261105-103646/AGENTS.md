## Working rules

- Inspect before edits, preserve user work, record actual evidence in `harness/build-log.md`.
- TypeScript workspaces: `apps/game`, reserved `apps/admin`, reserved `apps/server`, `packages/shared`.
- Bengali is the primary player language. All UI, signs, content and errors must be Unicode Bengali. Technical control keys may remain Latin. Never add Hindi, real political identities, logos, voices or faces.
- Use original or clearly licensed assets. Keep editable source and attribution. A visible geometric placeholder does not satisfy visual acceptance.
- Never claim real-device performance from viewport emulation. Never mark a requirement verified without observation.
- Before completing Phase 01 run types, lint, tests, production build, browser desktop/mobile checks, gameplay interaction checks and three screenshot angles. Record limitations and any failed gate.
