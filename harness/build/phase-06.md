# Phase 06: Optimization, QA and release

## Purpose

Optimization, QA and release for the standalone Bengali game.

## Scope

Real desktop/Android; Bengali shaping; multiplayer/security/upload testing; profiling/LOD/compression; production/deployment/recovery docs.

## Non-goals

Unapproved feature expansion.

## Dependencies

Explicit approval and prior phase acceptance.

## Acceptance criteria

Measured target devices, correct Bengali, documented secure deploy/recovery and asset license coverage.

## Verification plan

Hardware FPS/profiling, release smoke/security tests, rollback drill, font screenshots.

## Approval gate

Do not deploy or call production-ready without evidence and explicit release authorization.
