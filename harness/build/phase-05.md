# Phase 05: Multiplayer and referrals

## Purpose

Multiplayer and referrals for the standalone Bengali game.

## Scope

Colyseus 2–6 players; private invite; host; authoritative score/pickups; prediction/interpolation/reconnection; referral cosmetic and abuse prevention.

## Non-goals

Production release without Phase 06.

## Dependencies

Explicit approval; current server/client package versions; persistence/presence plan.

## Acceptance criteria

Clients converge; no duplicate rewards; reconnect and private lobby work in Bengali.

## Verification plan

Multi-client latency/disconnect tests, authority and abuse tests, lobby mobile check.

## Approval gate

Do not start without explicit user approval.
