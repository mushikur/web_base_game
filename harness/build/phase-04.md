# Phase 04: Bengali content Admin

## Purpose

Bengali content Admin for the standalone Bengali game.

## Scope

End-to-end content draft, preview, publish, rollback, audit; portraits/templates and validated rigged GLB; owned voice/subtitle upload; MongoDB/object storage.

## Non-goals

Multiplayer and referral.

## Dependencies

Explicit approval; upload/security design and game content contract.

## Acceptance criteria

Saved content truly changes game; invalid models cannot publish; Bengali required for all player content.

## Verification plan

Real Admin-to-game flows, permissions, upload validation, rollback and Bengali errors.

## Approval gate

Do not start without explicit user approval.
