# Phase 01: Dhaka vertical slice

## Purpose

Dhaka vertical slice for the standalone Bengali game.

## Scope

One street; tea shop; animated GLB player; movement/camera; 1 leader, 3 workers, 5 civilians; rickshaw/CNG; egg/sandal throw; collision, health, score, minimap, lighting, traffic audio, Bengali UI and quality presets.

## Non-goals

Complete city, full action system, driving, news, Admin, multiplayer and referral.

## Dependencies

Phase 00; licensed original assets; Babylon/Havok/Vite and Bengali shaping font.

## Acceptance criteria

All listed features operate; no visible placeholder primitives; desktop/mobile render correctly; requirements have recorded evidence.

## Verification plan

Types, lint, meaningful tests, production build/serve; desktop/mobile viewport; three angles; FPS; controls, collision, throws, presets, Bengali shaping and offline asset load.

## Approval gate

Stop and report measured results. User approval required before Phase 02; unmet criteria remain open.
