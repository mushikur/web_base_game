## Leader, worker, crowd and civilian behavior

Use separate behavior controllers consuming the shared navigation graph and mission facts. Avoid extending the main frame function into multiple inconsistent actor controllers. Movement uses actual position deltas and animation contacts; empty/blocked movement must not create footsteps or advance distance facts.

- **Leader:** speech/gestures → notice player → gesture/call workers → seek reachable cover → react by actual item → retreat/replan → flee along bounded authored escape alternatives → throw a clearly harmless original cartoon paper/soft prop with cooldown → non-graphic resting/defeated animation → wait for assistance → evacuation. Use bounded path retry, line-of-sight checks and avoidance; do not rotate in place or slide while pretending to run. Egg and sandal have distinct authored reaction choices without changing D's later action family. A fleeing leader must remain followable within mission bounds.
- **Workers:** authored guard/banner positions, fictional slogans, notice/alert, follow/protect leader without forming an impassable capsule wall, move away from observed incoming props, react to audible events, and visibly scatter toward safe exits after completion. Hit/voice reactions and gestures use the real rig. No hostile targeting/chase or contact damage while tutorial safety is enabled.
- **Crowd:** original 3D people with small offset idle/gesture/phone reactions, safe standing envelopes, reaction to actions/sirens and dispersal/return. Crowd and worker slogans use the existing published audio system; no real party recording or propaganda.
- **Civilians:** follow authored pavement paths, wait at crossings, yield to the limited C traffic loop, visit shop/tea entrances, move away from the active encounter, visibly use a phone where appropriate, react to the siren, and return to a valid prior path after completion. They never become mission targets or reward sources. Preserve the hub's ordinary patrol behavior when not reacting; use protected spawn envelopes/actual player avoidance so the new mission navigation does not undo B's idle-spawn safety.

Author initial states and crowd counts per area as data. Spawn/route conflicts are resolved from safe graph positions; never teleport through a wall or another character. B's tutorial gate overrides dangerous behavior before any state selection, not after damage occurs. Pauses and Settings freeze gameplay transitions, movement and pending dangerous actions; resume clears held input without replaying a burst of stale events.
