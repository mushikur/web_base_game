# Photo-led Phase 01 graphics revision — 2026-11-02

The user explicitly authorizes enhancing this existing game's vehicles, road, environment, graphics and animated 3D characters using eleven supplied local photographs. This extends the current Phase 01 art pass. It does not authorize Admin, a full city, driving, multiplayer, new databases or reproducing real political identities.

All originals remain unchanged in `D:/game image`. Copies, dimensions and SHA-256 hashes are archived in `assets/source/references/manifest.json`. The previous game source and GLB are preserved in `assets/source/archive/phase01-before-photo-upgrade.zip`.

Imagegen built-in mode produced one original four-material atlas from street/rickshaw/CNG references. Original output, exact prompt and derived local texture maps remain in the project. Approximate normal/ORM maps are explicitly described as computed maps, not scanned measurements. No complete photograph is used as a gameplay billboard or character face.

Lighting now uses a locally bundled 1k HDR pure sky from Poly Haven (Greg Zaal/Jarod Guest, CC0). Primary provenance: https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky and https://polyhaven.com/license. Download URL/metadata are retained in `assets/source/generated/environment-provenance.json`.

Characters remain original 17-joint skinned GLBs. The revision refines facial/anatomical proportions, cotton folds/collar/seams, articulated wrists and optional skinned panjabi/kameez/dupatta/long hair/moustache. Idle, Walk, Run, Throw, Hit and Pickup clips are blended; ambient civilian walking uses speed-matched animation. This is not a claim of photogrammetry, real-person reconstruction or cloth simulation.
